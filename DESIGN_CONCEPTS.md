# Webhedder Design Concepts - AI Prompts

## Design 01: Future Tech (Dark Neon)
**Theme:** Dark, futuristic, tech-focused
**Best for:** SaaS platforms, developer tools, tech startups

### AI Prompt:
```
Create a dark futuristic header with:
- Deep navy/slate background (#020617)
- Animated glowing blobs (cyan & purple) with blur
- Large bold heading with gradient text (cyan→purple→pink)
- Typewriter effect cycling through phrases
- Glassmorphism card with code snippet
- Floating animation on the right panel
- Neon-styled buttons with glow shadows
- Outfit/Inter fonts, 8xl heading size
```
