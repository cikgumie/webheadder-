## 🤖 Cara Guna AI Prompt

1. **Buka file HTML** mana-mana design
2. **Copy prompt** di bahagian atas (banner berwarna)
3. **Paste dalam AI** (Claude, ChatGPT, dll)
4. **Generate** design yang sama!

## ✨ Features

- ✅ **10 unique designs** - Setiap satu ada style sendiri
- ✅ **AI prompt built-in** - Copy & paste terus ke AI
- ✅ **Standalone files** - Setiap design boleh run sendiri
- ✅ **Tailwind CSS** - Modern, responsive design
- ✅ **Animations** - Typewriter effects, parallax, gradients
- ✅ **Production-ready** - Boleh guna terus
